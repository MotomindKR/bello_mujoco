# Controller prompts

Original, unmodified PNGs from JulioCacko's **FREE Input Prompts Pack 1.4**:
https://juliocacko.itch.io/free-input-prompts

Asset license: CC0 1.0 Universal. Commercial and non-commercial use allowed.
https://creativecommons.org/publicdomain/zero/1.0/

Imported from the user's `~/Downloads/Source` texture pack on 2026-09-29.
`provenance.json` records the original paths and SHA-256 hashes. Only the ten
used prompts for PlayStation 5, Xbox and Switch are included, in Default and
Light variants. The Light variant is displayed in system dark mode.

The original Xbox `T_X_X.png` is the Menu glyph, not the X face button.
Xbox `T_X_Share.png` is the View glyph. The `Share-1` glyph is a different
physical button and is not used. Internal prompt names follow runner semantic
inputs: A maps to Cross and Y to Triangle on PlayStation; L1/R1 map to LB/RB or L/R.

These controller assets intentionally use the user's requested raster pack.
Application navigation and other icons continue to use Lucide.
