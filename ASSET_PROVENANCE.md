# Bello asset provenance

The canonical Bello robot description is maintained in
`MotomindKR/bello-stack` under `descriptions/bello/`. This repository consumes
the exact revision pinned by the `deps/bello-stack` gitlink and embeds only its
full-body URDF plus referenced lower- and upper-body meshes in Python wheels.

Asset source commit:
`1b9c4b4759cdb5e358ad4e7cc595c5f996fdac75`.

The assets are proprietary. This repository does not grant permission to
redistribute them. The gitlink records the source revision used by each source
checkout and wheel build; external distribution requires a separate written
agreement with the applicable rights holder.
